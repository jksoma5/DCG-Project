# 09 벤데타 독립 실습 씬

## 구현 기준
2026-09-17 사용자 확정 동작을 기준으로 구현한다. 오버워치 벤데타를 3인칭으로 옮긴 조작 프로토타입이며, 원작 수치·애니메이션을 재현한 완성 캐릭터는 아니다.

- Shift: 바라보는 수평 방향으로 돌진한 뒤, 도착 위치에서 회전베기.
- E: 조준 방향으로 칼을 투척한다. 칼이 목적지에 도착하면 캐릭터가 칼까지 비행하고 멈춘다.
- 이번 스킬 범위는 Shift와 E만이다. 기본 공격, 방어, 궁극기, 패시브, E 도착 피해는 구현하지 않는다.

## 실행과 조작
Unity에서 `Assets/_DCG/Scenes/VendettaLab.unity`를 열고 Play한다. 기존 ControlLab과 별도 씬이며 기존 캐릭터 선택 메뉴에는 합치지 않았다.

| 입력 | 동작 |
| --- | --- |
| WASD | 카메라 수평 방향 기준 이동 |
| 마우스 | 3인칭 시점 및 조준 |
| Space | 지상 점프 |
| 왼쪽 Shift | 돌진 → 회전베기 |
| E | 조준 방향 투척 → 칼 정지 → 캐릭터 비행 → 도착 정지 |
| Esc / 좌클릭 | 커서 해제 / 다시 캡처 |
| F5 | 실습 씬 초기화 |

씬에는 지상 표적, 충돌 테스트 벽, 고지대와 표적이 있다. 주황색 칼과 연결선은 E의 이동 순서를, 원형 표시는 회전베기 범위를 보여준다. 캡슐과 칼은 임시 모델이다.

## 개발 구조
- `VendettaInputReader`: Input System의 Vendetta 맵에서 직접 이동 프레임과 Action 명령을 생성한다.
- `LocalSession`: 소유자·순서·수치 유효성을 검증하고 명령을 시뮬레이션에 전달한다.
- `IActorActionPolicy`: 공통 액터에 직업별 입력 검증, 상태, 이동 방식, 이동 후 처리를 연결한다. Gameplay는 Classes를 참조하지 않는다.
- `VendettaController`: Ready, Dash, Spin, SwordThrow, Flight 상태와 쿨다운을 관리한다. 기존 Graves 이동 정책과 분리한다.
- `CharacterMotor`: 평상시에는 중력과 CharacterController 이동, 비행 중에는 3차원 속도 이동을 수행한다.
- `ThirdPersonRig`: 마우스 시점과 카메라 충돌 보정.
- `VendettaLabController`: 씬 초기화, 시각 피드백, 안내 및 쿨다운 표시.
- `VendettaLabSetup`: 독립 씬·프리팹·설정 자산 생성과 전용 Windows 빌드.

Shift는 돌진 단계에서 피해를 주지 않는다. 회전베기 단계에서 범위와 차폐를 확인하고 대상별 1회 피해를 적용한다. 다른 스킬 수행 중이거나 쿨다운 중에는 다시 발동하지 않는다.

E는 캐릭터 캡슐의 진행 경로를 검사해 벽 앞에 목적지를 설정한다. 칼 투척 중 캐릭터의 직접 이동은 잠기며, 투척 완료 후 비행한다. 캐릭터의 손 높이 기준점이 칼에 도달하면 비행 속도를 제거한다. 공중 도착 후에는 일반 중력이 다시 적용된다. 이동 경로가 막혀도 무한 비행하지 않도록 정체·시간 제한으로 종료한다.

입력이 끊어지면 직접 이동이 만료된다. 사망 시 진행 중인 스킬과 이동을 중단한다.

## 조정 자산
`Assets/_DCG/Data/Classes/Vendetta_TuningPending.asset`에서 조정한다.

| 항목 | 초기값 |
| --- | --- |
| 기본 이동 / 점프 속도 | 5.5 / 7 |
| Shift 거리 / 돌진 시간 | 6 / 0.25초 |
| 회전 시간 / 반경 / 피해 | 0.35초 / 2.8 / 45 |
| Shift 쿨다운 | 5초 |
| E 거리 / 투척 시간 / 비행 속도 | 10 / 0.3초 / 20 |
| E 쿨다운 | 6초 |

모든 수치는 체감 확인용 미확정 값이다. 피격 판정·피해는 공통 DamageSystem을 사용한다. 차후 애니메이션과 효과는 상태를 읽는 표현 계층에 연결한다.

## 생성·빌드·검증
- 씬 재생성: Unity 메뉴 `DCG/Generate Vendetta Lab`
- 전용 빌드: `DCG/Build Windows Vendetta Lab`
- 출력: `Builds/VendettaLab/DCG-VendettaLab.exe`
- 테스트: Test Runner의 EditMode와 PlayMode 전체 실행.
- 자동 검증: Unity를 닫은 뒤 `Tools/Verify-Dcg.ps1 -Regenerate -Build -BuildVendetta`.
- 플레이어 자동 점검: 빌드 실행 인수 `-vendettaReportPath <출력 폴더>`를 주면 스킬 실행 결과 JSON과 카메라 이미지가 기록된다.

VendettaTests는 Shift 순서·단일 피해·쿨다운, E 투척 후 비행·정지·피해 없음, 벽 충돌, 잘못된 입력 거부, 입력 만료와 사망 중단을 확인한다.

## 이후 통합
별도 씬에서 이동·시점·거리·타이밍을 확정한 후 공통 캐릭터 생성과 선택 UI에 Vendetta 프리팹을 연결한다. 네트워크용 상세 스킬 상태 복제, 실제 캐릭터 모델·애니메이션·효과음은 후속 작업이다. 현재 공통 스냅샷의 ActionState는 요약 상태이며, 투척 칼 위치와 세부 단계의 원격 표현은 아직 별도로 복제하지 않는다.
