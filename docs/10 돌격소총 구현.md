# 10 숄더뷰 돌격소총 구현

## 기준과 범위
기획의 Shoulder / 돌격소총 = 배틀그라운드 M416을 따른다. 사용자는 2026-09-17에 **숄더 조준 + 1인칭 ADS** 방식을 선택했다.
벤데타처럼 독립 `RifleLab` 씬에서 조작을 검증하고, 통합 캐릭터 선택과 대전 연결은 후속 작업으로 둔다.

PUBG 공식 PC 조작 안내: https://support.pubg.com/hc/en-us/articles/360002074913-What-are-the-basic-game-commands
공식 페이지에서 이동, 자세, Q/E, 우클릭 유지 Aim / 짧은 클릭 ADS, Alt 둘러보기를 확인했다. 해당 안내의 업데이트 날짜는 2020-08-03이며, 현재 사용자의 커스텀 키 설정이나 원작 프레임·수치를 검증한 자료는 아니다.

## 실행
Unity에서 `Assets/_DCG/Scenes/RifleLab.unity`를 열고 Play.
별도 실행 파일: `Builds/RifleLab/DCG-RifleLab.exe`.

| 입력 | 구현 동작 |
| --- | --- |
| WASD / 마우스 | 시선 기준 이동 / 회전 |
| Shift + 전진 | 질주, 조준·사격 시 질주 해제 |
| Ctrl | 느리게 걷기 |
| Space | 점프 |
| C / Z | 앉기 / 엎드리기 전환 |
| Q / E | 좌우 기울이기, 숄더 조준 중 어깨 방향 선택 |
| 좌클릭 | 발사. Auto는 유지 연사, Single은 누를 때 1발 |
| 우클릭 짧게 | 1인칭 ADS 전환 |
| 우클릭 길게 | 숄더 조준, 놓으면 해제 |
| B / R | 단발·연사 전환 / 재장전 |
| Alt + 마우스 | 비조준 상태에서 자유 둘러보기 |
| Esc / 좌클릭 | 커서 해제 / 다시 캡처 |
| F5 | 씬 초기화 |

질주·앉기·엎드리기·조준은 서로 다른 이동 속도를 사용한다. 자세 변경은 CharacterController와 피격 캡슐의 높이를 함께 바꾸며, 천장에 막히면 일어서지 않는다. 기울이기도 엄폐 충돌을 검사한다. 입력 포커스를 잃으면 이동·사격 입력을 해제하고, 입력이 끊어지면 시뮬레이션에서 만료시킨다.

## 사격
카메라 중앙으로 조준점을 구한 뒤 실제 총구에서 탄환을 발사한다. 총구가 벽을 뚫고 나가는 경우는 발사를 차단한다. 탄환은 고정 틱마다 이동 구간을 Raycast하여 고속 이동 중 충돌 누락을 줄이고, 중력과 최대 사거리를 적용한다. 카메라에서 표적이 보여도 탄환 경로에 엄폐물이 있으면 피해를 주지 않는다.

한 발당 탄창 1발을 소비한다. 재장전 완료 시 예비 탄약을 탄창으로 옮기며 총 탄약량을 보존한다. 빈 탄창은 R로 재장전한다. 단발은 새 누름 입력이 필요하다. 연사 타이밍은 고정 틱에서 남은 시간을 누적하여 처리한다.
비조준·숄더·ADS의 탄 퍼짐, 자세와 이동에 따른 퍼짐, 수직 반동과 회복을 구분한다. 히트 마커와 짧은 탄도 선을 표시한다.

## 구조
- `RifleInputReader`: Rifle 입력 맵, 카메라 조준점, 커서·자유 시점 처리, DirectControl/Action 명령 생성.
- `RifleAimGesture`: 우클릭 탭과 홀드 판정을 순수 상태로 분리. 홀드 해제를 ADS 탭으로 처리하지 않는다.
- `RifleController`: 이동·자세·조준·탄약·발사 모드·반동·탄환 시뮬레이션. 기존 `IActorActionPolicy`로 액터에 연결.
- `IActorAmmoSource`: 공통 스냅샷이 소총 탄창 수를 읽는 작은 인터페이스.
- `ShoulderCameraRig`: 어깨 카메라 충돌, ADS 위치와 시야각, 기울이기 표현. Classes 참조 없이 작동.
- `RifleLabController`: 조합·임시 모델·총구·ADS 총 모델·HUD.
- `RifleLabSetup`: 별도 씬·프리팹·튜닝 생성과 전용 빌드.
- `RifleSmokeProbe`: 명령줄 자동 플레이어 점검.

총기와 자세·조준 상태를 분리했다. Gameplay에서 Classes를 참조하지 않으며, Graves와 Vendetta의 입력 맵·씬은 유지한다.
`DirectControlFrame.AimTarget`은 카메라 중앙의 월드 조준점이다. 로컬 세션에서 유한값과 거리를 검증한다. 원격 대전 도입 시 서버 시점 검증과 지연 보정이 추가로 필요하다.

## 튜닝
`Assets/_DCG/Data/Classes/Rifle_TuningPending.asset` 사용.
탄창 30 / 예비 120, 발사 간격 0.086초, 재장전 2.3초, 피해 35, 탄속 880, 거리 180이 초기값이다.
이동·자세 속도, 퍼짐·반동, 시야각, 카메라 거리와 마우스 감도도 이 자산에서 조정한다. 모두 원작 수치 측정 전의 프로토타입 값이다.

## 생성과 검증
- Unity 메뉴 `DCG/Generate Rifle Lab`, `DCG/Build Windows Rifle Lab`.
- Unity를 닫은 상태에서 `Tools/Verify-Dcg.ps1 -BuildRifle`: 전체 테스트 후 소총 빌드.
- `-Regenerate`: 세 실습 씬을 재생성하므로 씬 수동 편집을 보관한 뒤 사용한다.
- 플레이어 자동 점검 인수: `-rifleReportPath <결과 폴더>`.
- 결과 파일: `Logs/rifle-editmode.xml`, `Logs/rifle-playmode.xml`, `Logs/rifle-build.log`, `Logs/rifle-smoke/rifle-smoke.json`.

## 후속 범위
현재는 조작과 사격을 확인할 임시 모델이다. 원작 애니메이션·효과음·정확한 반동 패턴, 헤드샷·방어구·부착물, 파쿠르·문·아이템·인벤토리·무기 교체, 숨 참기, 전체 1/3인칭 전환(V), 원격 멀티플레이는 포함하지 않는다.
엎드리기는 낮은 캡슐과 임시 모델로 표현하며 원작 전신 지형 충돌·애니메이션을 재현한 상태는 아니다. 상세 상태 복제와 탄환 수명 관리는 네트워크 도입 시 공통 탄환 서비스로 옮길 수 있다.

## 최종 검증 기록 — 2026-09-17
- EditMode 15/15, PlayMode 21/21: 총 36개 통과. Graves·Vendetta 회귀 테스트 포함.
- Windows 개발 빌드 성공. ADS 가늠쇠 위치를 화면 중앙 기준으로 보정하고 최종 플레이어 캡처에서 확인.
- 최종 플레이어 자동 점검: passed=true, 10발 발사, 표적 체력 0, 재장전 후 탄창 30.
- 플레이어 로그에 Exception, NullReference, MissingReference, C# 오류 없음.
- 기존 ControlLab·VendettaLab·Bootstrap 씬 보존. 새 씬·프리팹의 자산 참조 누락 및 C# 메타데이터 누락 없음.
- 최종 실행 결과: `Logs/rifle-smoke-final/rifle-smoke.json`, `Logs/rifle-player-final.log`.
- 화면: `Logs/rifle-smoke-final/rifle-shoulder.png`, `rifle-aim.png`, `rifle-ads.png`. 카메라 렌더 캡처로 IMGUI HUD는 포함하지 않는다.
- 자동 점검은 시뮬레이션 명령을 사용한다. 실제 마우스 감도와 원작 체감 비교는 플레이 후 조정한다.
