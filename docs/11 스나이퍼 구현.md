# 11 1인칭 저격수 구현

## 확정 범위
- 기존 기획의 1인칭 / 서든어택 TRG 계열 조작을 개발한다.
- 사용자 지정: 숫자 1 = 저격총, 2 = 권총, 3 = 칼.
- 독립 `SniperLab` 씬에서 먼저 검증한다. 기존 세 직업의 씬과 입력은 유지한다.
- 권총과 칼의 구체적인 원작 모델은 미지정이므로 기본 프로토타입으로 둔다.

## 실행과 조작
Unity에서 `Assets/_DCG/Scenes/SniperLab.unity`를 열고 Play한다.
Windows 실행 파일은 `Builds/SniperLab/DCG-SniperLab.exe`.

| 입력 | 동작 |
| --- | --- |
| WASD | 시선의 수평 방향 기준 이동, 놓으면 수평 이동 즉시 정지 |
| Shift 유지 | 걷기 감속 |
| Ctrl 유지 | 앉기, 놓으면 일어서기 시도 |
| Space | 지면에서 점프 |
| 마우스 | 1인칭 시선 |
| 1 / 2 / 3 | 저격총 / 권총 / 칼 |
| 좌클릭 | 저격·권총 단발 / 칼 베기 |
| 우클릭 | 저격총 조준경 단계 전환 / 칼 찌르기 |
| R | 현재 총기 재장전 |
| Esc / 좌클릭 | 커서 해제 / 다시 캡처 |
| F5 | 실습 초기화 |

기본 이동은 가속 보간 없이 즉시 반응하도록 했다. 대각선 입력은 정규화한다. 별도 질주 대신 Shift 걷기를 사용한다. 칼 > 권총 > 저격총 순서의 이동 속도와 걷기·앉기 배율을 설정에서 조정한다.
공중에서도 수평 방향 입력을 처리하지만 버니합·점프 가속·원작의 특수 이동 기술을 임의로 추가하지 않는다. 이동 속도, 점프 궤적과 공중 조작은 원작 실측 비교 전이다.

## 무기 상태
세 무기는 슬롯마다 탄창·예비 탄약·재사용 대기시간을 보관한다. 전환 시 탄약을 다시 채우지 않는다. 무기를 바꾸면 조준경과 진행 중인 재장전은 해제되고 장착 시간이 적용된다. 원래 무기로 돌아와도 남은 발사 대기시간은 유지한다.

- 저격총: 초기 5/20발. 우클릭은 일반 → 1단 조준 → 2단 조준 → 일반 순서. 발사하면 조준을 해제하고 다음 발사까지 기다린다.
- 권총: 초기 12/48발. 새 좌클릭 누름마다 한 발. 저격총과 탄약을 공유하지 않는다.
- 칼: 탄약 없음. 좌클릭 베기와 우클릭 찌르기에 서로 다른 피해와 후딜을 부여한 임시 설정. 시선 방향의 근접 판정이므로 겨냥한 첫 표적만 맞는다.
- 재장전: 종료 시점에 예비 탄약을 탄창으로 이동한다. 도중 무기 변경·사망은 완료 처리를 취소한다.
- 발사·근접 판정: 시뮬레이션의 시선 기준 Raycast. 벽과 지면이 공격을 막으며 아군·자신에게 피해를 주지 않는다. 이번 총기는 즉시 명중 판정을 사용한다.

저격 조준 단계, 발사 뒤 자동 재조준 여부, 교체로 후딜을 단축하는 원작 세부 동작은 프레임 단위 실측을 하지 않았다. 현재는 위 규칙을 명시적인 프로토타입 동작으로 사용하고, 원작 재현 완료로 표시하지 않는다.

## 구조
- `SniperTuning`: 이동·점프·세 무기 수치·시야각·감도. `Data/Classes/Sniper_TuningPending.asset`.
- `SniperInputReader`: Sniper 입력 맵. 슬롯 변경 명령을 먼저 보내고 해당 프레임 이동·공격을 보낸다.
- `SniperController`: `IActorActionPolicy`와 `IActorAmmoSource`를 구현한다. 무기 상태·조준·재장전·사격·근접·자세를 처리한다.
- `FirstPersonScopeRig`: 1인칭 카메라와 실제 렌더링되는 원형 조준경 마스크·십자선. Classes를 참조하지 않는다.
- `SniperLabController`: 세 임시 무기 모델, 장착·발사 시각 피드백, HUD, 씬 초기화.
- `SniperLabSetup`: 씬·프리팹·자산 생성, 전용 Windows 빌드.
- `SniperSmokeProbe`: 별도 플레이어에서 스코프·발사·무기 전환 캡처와 결과 기록.

Core의 `ControlButtons.Crouch`를 추가했으며, 다른 직업 입력 검증은 기존 허용 마스크를 유지한다.
같은 공통 모터와 피해 시스템을 사용하지만 배그의 질주·엎드리기·숄더 조준을 저격수에게 적용하지 않는다.
향후 대전 통합 시 선택 무기·슬롯별 탄약·조준 단계·재장전 상태의 네트워크 복제가 추가로 필요하다.

## 설정과 한계
거리·속도·피해·쿨다운은 `TuningPending`이다. 공식 무기 안내에서 TRG-21의 5/20 장탄과 볼트액션 설명을 확인했다.
참고: [서든어택 공식 주무기 가이드](https://guide.sa.nexon.com/guide/39), [기초 단축키 훈련 안내](https://guide.sa.nexon.com/guide/92).
문서만으로 원작의 이동 프레임·정확한 감도·연사 취소·애니메이션 타이밍까지 확인한 것은 아니다.

현재 캡슐·저격총·권총·칼은 임시 모델이다. 원작 모델·사운드·애니메이션, 헤드샷과 부위별 배율, Q 이전 무기 전환, 휠 전환, 무기 버리기·줍기, 특수 캐릭터 기능, 네트워크 대전은 이번 범위에 포함하지 않는다.

## 검증 방법
- 메뉴: `DCG/Generate Sniper Lab`, `DCG/Build Windows Sniper Lab`.
- Unity를 닫고 `Tools/Verify-Dcg.ps1 -BuildSniper`: 전체 테스트 후 전용 빌드.
- `-Regenerate`는 네 실습 씬을 재생성하므로 씬 수동 편집은 별도 보관한다.
- 플레이어 자동 점검 인수: `-sniperReportPath <결과 폴더>`.
- 결과 경로: `Logs/sniper-editmode.xml`, `Logs/sniper-playmode.xml`, `Logs/sniper-build.log`, `Logs/sniper-smoke/sniper-smoke.json`.

- 최종 결과는 `Logs/sniper-smoke-final/sniper-smoke.json`, `Logs/sniper-player-final.log`와 같은 폴더의 PNG에 있다.

- 실제 사람의 이동·마우스 체감과 원작 프레임 비교는 후속 튜닝이다.
