# 13 폴 조작 명세 및 1차 구현

## 기준과 범위
- 사용자 확정 기준 버전: 철권 7.
- 방향: WASD. 공격: U/I/J/K = 1/2/3/4, O = 1+2, L = 3+4.
- 독립 PaulLab에서 60Hz로 진행한다. 전역 Fixed Timestep 0.02는 유지한다.
- 이동 공간의 별도 답변이 없어 첫 구현은 3D 횡이동을 포함한다. Paul_Moves의 allowSidestep으로 제한할 수 있다.
- 12 계획의 2-1을 반영해 상황별 피격 결과, 띄우기·공중 추가타·날려서 다운·자동 기상까지 확장했다. 원작 전 기술이나 완성된 철권 전투를 재현한 상태는 아니다.

동시 입력은 최초 누름부터 2프레임 동안 모아서 판정한다. 이에 따라 단일 버튼도 기본 2프레임 판정 지연이 있다. O와 U+I, L과 J+K는 같은 공격 비트로 취급한다.
1+3, 2+4, 2+3, 네 버튼 동시 입력도 입력 기록과 파서에서 구별한다. 기술을 배정하지 않은 조합은 Unassigned로 표시하고 단일 공격으로 대체하지 않는다.
키보드 하드웨어의 고스팅은 자동 테스트로 검증할 수 없으므로 실제 키보드에서 확인해야 한다.

## 방향과 시간
Facing은 두 캐릭터의 실제 평면 위치로 상대를 향한다. 입력 해석용 Side는 X좌표로 결정하고, 작은 X 차이에서는 이전 Side를 유지한다. 두 Side는 항상 반대이며 공격·경직·공중 상태 중에는 Side 전환을 보류한다. 따라서 Facing과 입력 해석 Side는 공격 중 위치가 뒤집혔을 때 일시적으로 다를 수 있다.
InputBuffer는 원시 입력과 당시 Side·상대 방향 해석을 함께 보관하므로 과거 입력을 다시 뒤집지 않는다.

FrameClock은 1/60초를 누적하고 한 렌더 프레임에 처리할 수 없는 시간은 남겨 둔다.
PaulLab에서만 Input System을 수동 처리한다. 입력 콜백의 타임스탬프를 보관하고 각 60Hz 경계까지의 이벤트를 샘플링한다. 렌더 한 번에 입력 이벤트가 몰려도 과거 프레임의 방향 순서를 보존한다.
씬 종료 또는 입력 리더 비활성화 시 이전 Input System 업데이트 모드를 복원한다. 입력이 15프레임 이상 끊어지면 중립으로 바꾼다.

## 전투와 더미
FighterMatch가 두 캐릭터를 함께 진행하고, 양쪽 접촉 결과를 모두 캡처한 뒤 DamageSystem으로 피해를 적용한다. 먼저 처리된 액터가 상대 공격을 지워 동시 타격을 막지 않도록 한다.
MoveData의 발동·판정·후딜은 정수 프레임이다. 기술별 한 번만 피해를 주며, 상태 태그로 회피·가드·파워크래시·공중·다운·카운터 결과를 선택한다.
이득 프레임은 타격 순간 공격자의 남은 후딜에 지정 이득을 더해 상대 경직을 설정하는 방식이다. pushback 필드의 밀어내기와 launchHeight/horizontalSpeed에 따른 공중 이동을 지원한다. 히트 스톱·애니메이션 기반 히트박스는 없다. 거리와 높이 종류에 따른 단순 접촉 판정이며, 표시 박스는 디버그 표현이다.
전부 가드 더미는 예정된 공격 높이에 맞춰 가드하고 제자리에 선다. 입력 녹화는 최대 3600프레임이며, 당시 상대 방향으로 기록하여 반대편 더미에서도 같은 커맨드가 되도록 재생한다.

### 결과 선택과 상태 실행

1. 잡기는 전용 풀기 구간이 필요하므로 현재 미배정이며 Resolver에서 Miss. 일반 타격 결과로 대체하지 않는다.
2. High/LowCrush, 상단 앉기 회피, 비호밍 공격의 횡이동 회피를 확인한다.
3. 공중·다운·등 돌림·공격·경직 중이 아닐 때 가드 자세와 공격 높이를 비교한다. SpecialMid는 서서/앉아 가드 모두 허용한다.
4. 파워크래시는 상·중단 피해를 받되 공격을 유지한다. 하단에는 적용하지 않는다.
5. 공중/다운 결과를 우선 사용하며 미정의 결과는 Miss.
6. 전역 FightMoveSet.counterStates에 맞으면 카운터, 그 외 일반 히트. 초기 설정은 문서 지시대로 AttackStartup | AttackActive이며 원작 미확정이다. AttackRecovery는 제외한다.
7. 양쪽 결과·피해·밀리는 방향을 먼저 캡처한 후 적용하여 동시 띄우기와 치명타 상쇄를 보존한다.

HitOutcome/BlockOutcome은 MoveData 소유, 결과 선택은 HitOutcomeSelector/FightResolver, 실행은 피격자의 FighterStateMachine이다. FighterAgent는 선택한 반응 속도를 CharacterMotor로 실제 이동시킨다. 더미 HoldPosition은 자발적 이동만 막으며 피격으로 날아가는 이동을 막지 않는다.

Airborne은 단순 경직 만료로 풀리지 않는다. 중력으로 낙하해 바닥에 닿으면 Down 36F → GettingUp 18F → 중립. 현재는 자동 정면 기상만 지원한다. 공중·다운 중 일반 이동/공격/가드를 차단하고 Side 전환을 보류한다. turnDefender가 설정된 반응에서는 경직 동안 등 돌림·가드 불가가 적용된다.

공중 추가타 피해는 max(0.2, 0.7 - 누적 juggleCost × 0.1) 배율이다. 추가타 후 cost를 누적하며 기본 한도 6에서 상승 속도를 제거한다. 연속 추가타와 두 번째 Screw로 무한히 다시 띄우지 못한다. 수치와 규칙은 원작 콤보 보정이 아닌 검증용이다.

Crumple/Spin은 강제 앉기/회전 경직의 기본 반응을 지원하며 아직 실제 폴 기술에 배정하지 않는다. 벽꽝·벽 반동·잡기 풀기·낙법·레이지는 미구현이다. 정교한 애니메이션과 히트박스 대신 높이/거리 판정 및 디버그 모델로 확인한다.
