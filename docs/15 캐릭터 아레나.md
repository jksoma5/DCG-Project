# 15 캐릭터 아레나

2026-09-23. docs 05~14의 공통 시뮬레이션, 캐릭터별 조작 및 통합 맵을 재사용한다.

## 실행

`Assets/_DCG/Scenes/CharacterArena.unity`를 열고 Play를 누른다.
기본 선택은 그레이브즈이며 그레이브즈, 벤데타, M416, TRG, 폴이 각각 한 명씩 광장에 등장한다.
시작 및 F5 재시작 시 선택한 캐릭터는 광장 중앙, AI 네 명은 광장 네 모서리에 배치한다.
AI 시작 좌표는 광장 중심 기준 (-27, 0, -13), (15, 0, -13), (-27, 0, 13), (15, 0, 13)이며 벽에서 3m 안쪽이다.
실시간 캐릭터 전환 시에는 재배치하지 않고 현재 위치를 유지한다.
기존 ControlHub 및 개별 Lab 씬은 연습용으로 유지한다.
씬 재생성 메뉴: `DCG > Generate Character Arena` (현재 ControlHub 맵을 복사한다).

## 실시간 캐릭터 선택

| 키 | 캐릭터 |
| --- | --- |
| F8 | 그레이브즈 |
| F9 | 벤데타 |
| F10 | M416 |
| F11 | TRG |
| F12 | 폴 |
| Esc | 마우스 선택 열기/닫기 |
| F5 | 전투 전체 재시작 |

선택한 캐릭터만 플레이어 팀(0), 나머지 네 명은 적 팀(1)이다.
선택을 바꾸면 이전 캐릭터는 적 AI가 조작하고 새 캐릭터의 고유 조작 및 카메라를 사용한다.
TRG 무기 선택 1/2/3과 폴 연습 키 F1~F7을 피하기 위해 F8~F12를 사용한다.
전환은 같은 액터를 유지하며 위치, 체력, 탄약 및 진행 중인 전투 상태를 새로 만들지 않는다.
입력 소유자가 바뀔 때 대기 중인 이전 입력과 시퀀스 번호를 정리한다.
죽은 캐릭터는 선택할 수 없다. 플레이어가 죽으면 생존자를 선택하거나 F5로 재시작한다.
선택 메뉴에서도 세계의 시간은 진행되며, 메뉴를 연 캐릭터의 입력은 비활성화된다.

## 적 동작

시작/재시작 후 2초 준비 시간을 준다.
그레이브즈는 기존 경로 탐색과 타깃 공격을 사용한다.
벤데타는 접근 후 대시/회전 공격을 사용한다.
M416과 TRG는 시야가 확보되면 간격을 두고 사격하고 빈 탄창을 재장전한다.
폴은 플레이어에게 접근해 잽을 사용한다. 폴을 직접 조작할 때에는 가장 가까운 생존 적이 격투 타깃이다.
적끼리는 같은 팀이며 플레이어를 공격 대상으로 삼는다. 전환 직후부터 팀 관계가 바뀐다.
총기/벤데타 AI 이동은 기본 직접 이동이므로 복잡한 엄폐 우회 전술은 구현 범위 밖이다.
기존 프로토타입 모델과 TuningPending 수치를 사용하며, 완성형 전투 밸런스가 아니다.

## 검증

CharacterArenaTests: 5명 유지, 반복 조작권 전환, 팀 관계, 입력 맵/카메라 단일화,
체력·위치·탄약 유지, 입력 시퀀스 인계, 사망 후 선택 제한, 전체 재시작, 적의 실제 공격을 검사한다.
기존 EditMode/PlayMode 회귀 검증과 함께 실행한다.

최종 자동 검증 (Unity 6000.5.5f1, batchmode):

- PlayMode: 83/83 통과, 실패 0.
- EditMode: 34/34 통과, 실패 0.
- F11 실제 입력 이벤트를 통한 전환과 메뉴 복귀 검증 포함.
- 렌더링 화면과 조작 감각의 수동 플레이 검증은 수행하지 않음.

## 체력 및 체력바

아레나의 다섯 캐릭터는 각 기본 최대 체력의 5배로 시작한다. 원본 튜닝 에셋과 연습 씬의 체력은 변경하지 않는다.
캐릭터 전환은 현재 체력을 유지하며, F5는 5배 최대 체력으로 초기화한다(배율 중첩 없음).
화면에 보이는 캐릭터 머리 위와 하단 캐릭터 선택란에 현재/최대 체력을 표시하는 체력바를 제공한다.
선택 캐릭터는 초록색, 적은 빨간색이며 화면 밖 캐릭터도 하단에서 체력을 확인할 수 있다.
